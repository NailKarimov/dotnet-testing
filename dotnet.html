The room is already booked 10:00–11:00. Pick the new booking's times. The rule in code: b.Start < end && start < b.End. Mutant M1 turns "<" into "≤", and back-to-back meetings start to clash.

02

В памяти или на сокете

In memory or on a socket

WebApplicationFactory<Program>

Приложение целиком в памяти: настоящая маршрутизация, привязка тела, ProblemDetails — без порта. Каждый тест получает свежее приложение и поддельные часы через DI. 36 тестов API и 11 сценариев Reqnroll.

The whole app in memory: real routing, body binding and ProblemDetails, with no port. Every test gets a fresh app and a fake clock through DI. 36 API tests and 11 Reqnroll scenarios.

builder.UseEnvironment("Production");
builder.ConfigureServices(s =>
    s.AddSingleton<TimeProvider>(Clock));
App.Create() on Kestrel

Браузеру нужен настоящий сокет, а у TestServer его нет. UI-тесты запускают то же приложение на 127.0.0.1:0 и читают выданный порт из app.Urls. 7 тестов в Chromium, трейс Playwright для каждого упавшего.

A browser needs a real socket, and TestServer has none. The UI tests start the same app on 127.0.0.1:0 and read the bound port from app.Urls. 7 tests in Chromium, a Playwright trace for each failure.

var app = App.Create([], s => s.AddSingleton(clock));
app.Urls.Add("http://127.0.0.1:0");
await app.StartAsync();
